PnPInk Assets

This repository is made for PnPInk. With PnPInk you do not need to download and place images by hand: you can write something like @{pnp://egg}~i7^ and let PnPInk fetch, rotate, scale and place that asset automatically into one region of a card or across hundreds of generated cards.
PnPInk repositoryGuideHelp / Quickstartassets-index.json
Example: @{pnp://egg}~i7^ in a PnPInk dataset can resolve an asset from this repository and fit it into a placeholder automatically while generating a whole deck.
